## Scope

This is a comprehensive, versioned seed database covering IT/tech domains, occupations, job titles, departments, certifications, skills, knowledge, software, tools, databases, work activities, career language, learning resources, portals, companies, HR/staffing, interview terminology, standards, protocols and infrastructure.

It is not represented as a permanently exhaustive list. Technology names, credential catalogs, employer titles and market terminology change continuously. Use `last_verified`, `source_name`, `verification_status` and `active_status` when updating it.

## Recommended uses

- Search autocomplete and synonym expansion
- MapIT career taxonomy and role/resource tagging
- Job and resume keyword matching
- Interview question indexing
- Course and certification catalog classification
- IT vendor, portal and consultancy directories
- Knowledge graph or vector-search ingestion

## Update guidance

Create a new version rather than overwriting source fields. Re-import official data sources, compare normalized keys, mark removed products or credentials as archived where known, and preserve aliases for backward-compatible search.
